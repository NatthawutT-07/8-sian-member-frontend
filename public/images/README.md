# โลโก้ร้าน

นำภาพโลโก้มาวางในโฟลเดอร์นี้ ชื่อ `logo.png`

- Path ในเครื่อง: `C:\Project_Code\member-sian\frontend\public\images\logo.png`
- URL บนเว็บ: `/images/logo.png`
- แนะนำ PNG พื้นหลังโปร่งใส ทรงสี่เหลี่ยมจัตุรัส ขนาดประมาณ 512 × 512 px

โลโก้จะแสดงที่เมนูหน้าแรก ท้ายหน้า และเมนูหน้าสมาชิก หากยังไม่ได้วางไฟล์ ระบบจะแสดงตราตัวอักษรเดิม

หากใช้ JPG หรือ WebP ให้เปลี่ยน src ใน `src/components/BrandLogo.jsx` ให้ตรงชื่อไฟล์
