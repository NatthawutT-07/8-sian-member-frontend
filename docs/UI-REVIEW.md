# ตรวจ UI และการปรับปรุง

ตรวจจากโครงสร้างหน้าและ CSS วันที่ 26 ตุลาคม 2569 ยังไม่ได้ยืนยันด้วย browser หรือมือถือจริงในรอบนี้

## จุดที่ปรับแล้ว

- หน้าแรกมี h1 ที่อธิบายว่าเว็บนี้ใช้รับคูปอง ปุ่มหลักพาไปดูโปรโมชั่น และปุ่มรองพาไปสมัคร
- ลดคำโปรยภาษาอังกฤษ วงกลมตกแต่ง สติกเกอร์ และข้อความประกอบที่ไม่ได้ช่วยตัดสินใจ
- ย่อภาพบัตรตัวอย่าง และซ่อนบนมือถือเพื่อให้เห็นโปรโมชั่นเร็วขึ้น โดยยังมีบัตรจริงในหน้าสมาชิก
- เปลี่ยนกล่องสิทธิพิเศษกว้าง ๆ เป็นขั้นตอนสมัคร รับคูปอง และแสดงบาร์โค้ดที่ร้าน
- เพิ่มหัวเรื่องหน้าสมาชิกแทนพื้นที่ว่าง และลดตัวอักษรตกแต่งในคูปอง
- เพิ่มขนาดข้อความช่วยเหลือในฟอร์ม desktop โดยคง input มือถือ 16px และพื้นที่กด 44px ตามเดิม
- ไม่แก้ข้อมูลแคมเปญ ราคา เงื่อนไขการรับ หรือ flow ตัดสิทธิ์

## จุดที่ควรตรวจบนเครื่องจริง

1. หน้าแรก /register /login /coupons ที่หน้าจอ 320, 375, 390 และ 768px รวมถึงเมื่อเปิดคีย์บอร์ด
2. ช่องวันเกิดบน Safari และ Chrome มือถือ ไม่ล้นและเลือกวันได้สะดวก
3. ชื่อโปรโมชั่นยาว เงื่อนไขปลดล็อกหลายบรรทัด และหน้าที่ไม่มีโปรโมชั่น
4. การเปิดบาร์โค้ด ความคมชัด และการอ่านด้วยเครื่องสแกนจริง

## สิ่งที่จะทำให้แบรนด์ชัดขึ้นในอนาคต

ใช้ภาพอาหารหรือหน้าร้านที่ถ่ายจริง 1-2 ภาพและข้อมูลร้านที่ตรวจสอบแล้ว จะช่วยเพิ่มบุคลิกได้มากกว่าการเพิ่มกราฟิกสำเร็จรูป ยังไม่ได้เพิ่มภาพหรือข้อมูลที่ร้านไม่ได้ให้มา
